# Floating Eye Software

This repository contains organization-wide resources for the Floating Eye Software GitHub organization.

Floating Eye Software (FLEY) is an independent software studio based in Toronto, Canada. We build software, publications, and technical infrastructure that emphasize privacy, quality, transparency, and long-term maintainability.

Our work spans several domains, including privacy-first health software, quality management systems, cooperative infrastructure, games, developer tooling, and technical publications.

## Projects

* **Pancakes** — a humane life platform for care, service exchange, and community governance.
* **Pitchfork** — an accounting substrate for symbolic economies, games, and cooperative systems.
* **Red Witch** — privacy-first menstrual and body tracking built around local-first data ownership.
* **fley-qms** — a lightweight quality management system for software projects.

## About this Repository

This repository exists to hold resources shared across the Floating Eye Software GitHub organization.

The organization profile shown on GitHub is defined in `profile/README.md`.

Project-specific documentation, design records, and development workflows belong in their respective repositories. Shared GitHub resources that are applicable across multiple repositories may be placed here as the organization evolves.
